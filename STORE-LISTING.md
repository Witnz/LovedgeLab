## LovedgeLab New Tab

**Short description (max 132 characters)**
A customisable Tokyo Night new tab: live colours, quick-site sketches, custom icons and a notepad. Syncs across your devices.

**Description**
LovedgeLab turns your new tab into a calm, good-looking dashboard that is entirely yours.

Live colours: start from Night, Storm, Moon or Day, then adjust any surface or accent with a colour picker. A real-time preview shows every change as you make it.

Quick sites: pin up to 12 favourite sites as large tiles, each with a tidy wireframe sketch. Choose from eight built-in layouts or upload your own SVG. Use the site's favicon or your own image as the icon.

Categories from your favourites bar: every folder becomes a tile that opens in place, so your bookmarks are one click away. Pick a glyph or upload an icon for each folder.

Notepad: Markdown with clickable tasks and highlighted code. Notes stay on your device.

Sync: your colours, sites, sketches and icons follow you between devices using your browser's own extension sync. LovedgeLab has no server and collects nothing.

A matching browser theme is included, and the settings page can build one from your own colours.

**Permission justifications** (paste one per permission)
- bookmarks: Reads the favourites bar, read only, so each folder can be shown as a category tile with its links. LovedgeLab never creates, edits or deletes bookmarks, and never copies them off the device.
- favicon: Shows each site's small icon next to its name in the quick sites and the expanded category lists, using the icons the browser has already cached.
- storage: Saves the user's colours, quick sites, sketches, custom icons and notepad text. Settings use the browser's synced extension storage; notes use local storage only.
- No host permissions, no remote code, no content scripts, no background page.

**Data disclosure answers**
- Collects personal data: No. Sells or shares data: No. Remote servers: None. Analytics or advertising: None.
- Data kept in the browser: user-entered settings and notes, which never leave the browser except through the browser's own sync.
- Uses remote code: No.

**Assets to prepare**
- Extension icon 128x128 (included at tab/icons/icon128.png), store logo 300x300 (render brand/logo.svg), and 1 to 6 screenshots at 1280x800 or 640x400.
- Suggested screenshots: the new tab in Night, the same in Day, the settings page with the live preview, and a category tile expanded.

**Notes for certification**
The extension replaces the new tab page and reads the favourites bar (bookmarks permission, read only) to show folders as tiles. The favicon permission shows site icons from the browser cache. The storage permission saves settings, which the browser syncs between the user's devices. There are no remote requests, no remote code and no analytics. To test: open a new tab, click the gear in the top right, change a colour and watch the preview update, add a quick site, upload an SVG or image, and add a folder with links to the favourites bar to see a category tile.
